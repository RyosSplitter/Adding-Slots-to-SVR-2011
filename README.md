# SVR 2011 PSP DLC roster experiment

Experimental PPSSPP build for US PSP ULUS10543. The DLC tab exposes eighteen separate test identities, IDs 51–68, using John Cena assets. These are test clones, not a finished 150-wrestler roster.

See the release instructions before testing. Keep the original ISO and back up savedata. Boot normally rather than loading an older savestate.

## Windows DLC Tab Manager

[Download the desktop application](https://github.com/RyosSplitter/Adding-Slots-to-SVR-2011/raw/refs/heads/main/downloads/SVR-DLC-Tab-Manager-Windows.zip). Extract the ZIP and double-click the `.exe`; keep its `data` folder beside it. Pick an ISO, choose which existing IDs the DLC tab permits, and save a new patched ISO. [Instructions and validation limits](app/README.md). NoModel identities still require working independent records and assets.
